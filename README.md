# Past Questions Lab — CSC 106 Microprocessor Systems

AI-powered Past Questions Examination & Learning Platform.

## Features
- Exam mode with timer, navigation, mark-for-review
- Practice mode with immediate feedback
- Detailed results & answer review
- Performance analytics, weak/strong areas
- AI Tutor grounded in the study guide
- Questions extracted from CSC 106 Study Guide PDF (no hallucinated answers)

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy to Vercel
1. Go to https://vercel.com/new
2. Import this repository
3. Deploy — you get a free `*.vercel.app` link instantly.
